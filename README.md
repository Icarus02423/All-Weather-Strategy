# 全天候策略项目

研究股票、国债、黄金和其他商品的风险预算配置，构建期货版全天候策略。

## 当前阶段

先建立 GitHub 仓库，再编写期货行情下载程序；后续逐步实现收益率计算、历史协方差估计、风险预算配置和回测。

## 数据计划

- 数据来源：同花顺 iFinD HTTP API，使用加权期货序列。
- 开始日期：2014-01-01；未上市品种从实际可用日期开始。
- 数据频率：日频，第一版下载收盘价。
- 股指期货：沪深300、中证500、中证1000。
- 国债期货：2年、5年、10年、30年国债。
- 商品期货：沪金、原油、沪铜、螺纹钢、豆粕。
- 下载脚本计划放在 `scripts/下载期货数据.py`，行情保存在本地 `data/futures/`。
- 保留未上市期间的空值，不向前或向后填充价格。

## 风险预算

股票、国债各占组合风险预算的三分之一，黄金、其他商品各占六分之一。这里是风险预算，不是资金配置权重；实际权重需要结合历史协方差计算。

## 本地配置与版本管理

接口凭证通过环境变量或项目根目录的 `.env` 配置，变量名为 `IFIND_REFRESH_TOKEN`，不写入代码或日志。

GitHub 保存代码、说明和不含凭证的配置模板；本地凭证、虚拟环境、PyCharm 配置、行情数据、运行结果及日志不上传。
