# 全天候策略项目

研究股票、国债、黄金和其他商品的风险预算配置，构建期货版全天候策略。

## 当前阶段

GitHub 仓库已建立。当前提供独立的行情下载程序；后续逐步实现收益率计算、历史协方差估计、风险预算配置和回测。

## 数据计划

- 数据来源：同花顺 iFinD HTTP API，使用加权期货序列。
- 开始日期：2014-01-01；未上市品种从实际可用日期开始。
- 数据频率：日频，第一版下载收盘价。
- 股指期货：沪深300、中证500、中证1000。
- 国债期货：2年、5年、10年、30年国债。
- 商品期货：沪金、原油、沪铜、螺纹钢、豆粕。
- 下载脚本放在 `scripts/下载期货数据.py`，行情保存在本地 `data/futures/`。
- 保留未上市期间的空值，不向前或向后填充价格。

## 风险预算

股票、国债各占组合风险预算的三分之一，黄金、其他商品各占六分之一。这里是风险预算，不是资金配置权重；实际权重需要结合历史协方差计算。

## 本地配置与版本管理

项目根目录的 `.env` 可以保存以下三项本地配置：

```dotenv
IFIND_USERNAME=
IFIND_PASSWORD=
IFIND_REFRESH_TOKEN=
```

当前脚本使用 HTTP 接口，仅读取 `IFIND_REFRESH_TOKEN`（环境变量优先），由它获取 `access_token` 后请求行情。`IFIND_USERNAME` 和 `IFIND_PASSWORD` 作为终端或 SDK 登录的备用账号配置，不是本脚本 HTTP 鉴权的必填项，也不会被本脚本读取、发送或记录。

真实凭证只保存在本机 `.env`，不写入代码、配置模板或日志。

GitHub 保存代码、说明和不含凭证的配置模板；本地凭证、虚拟环境、PyCharm 配置、行情数据、运行结果及日志不上传。

## 使用下载程序

程序仅使用 Python 标准库，兼容项目现有 Python 3.9 环境。

先离线查看代码配置（不读凭证、不联网）：

```bash
./.venv/bin/python scripts/下载期货数据.py --list
```

首次先核验各品种最早和最近各 14 个自然日的小样本：

```bash
./.venv/bin/python scripts/下载期货数据.py --probe
```

核验报告写入 `data/futures_probe/probe_report.csv` 和 `data/futures_probe/probe_samples.csv`，不生成或覆盖正式行情 CSV。可查询说明代码可用，仍需对照 iFinD 终端的“加权”全名及样本价格确认口径。CSV 中的名称来自本地品种配置，不是接口查询结果。

确认小样本和历史权限后，下载 2014-01-01 起的完整历史：

```bash
./.venv/bin/python scripts/下载期货数据.py
```

开始和结束日期可在程序顶部修改，或使用 `--start YYYY-MM-DD --end YYYY-MM-DD`。当前顶部配置的结束日期为 `2026-09-30`；将 `END_DATE` 留空才默认上海时间的昨天。程序保留接口交易日期，不另行移动夜盘日期。

使用 `--codes IF8888.CFE TF8888.CFE` 只处理部分品种。部分品种默认保存至 `data/futures_subset/`；可用 `--output 路径` 指定其他目录。程序不自动更换为主连、现货指数或具体月份合约。

## CSV 输出说明

所有输出均为 UTF-8-SIG 编码的 CSV，可直接在 Excel 中打开。完整下载成功后，默认在 `data/futures/` 生成 15 个文件：

```text
data/futures/
├── IF8888.CFE.csv
├── IC8888.CFE.csv
├── IM8888.CFE.csv
├── TS8888.CFE.csv
├── TF8888.CFE.csv
├── T8888.CFE.csv
├── TL8888.CFE.csv
├── AU8888.SHF.csv
├── SC8888.SHF.csv
├── CU8888.SHF.csv
├── RB8888.SHF.csv
├── M8888.DCE.csv
├── close_prices.csv
├── download_manifest.csv
└── data_issues.csv
```

### 单品种行情：每个品种一个文件

每行一个有行情的交易日，按日期升序，固定五列：

| 列名 | 内容 |
|---|---|
| 日期 | 接口返回的交易日期，格式 YYYY-MM-DD |
| 代码 | 对应的同花顺加权期货代码 |
| 名称 | 品种配置中的中文名称 |
| 资产类别 | 股票、国债、黄金或其他商品 |
| 收盘价 | 接口返回的日收盘价，数值列 |

上市前的日期不写入该品种文件，非交易日不补行。

### 收盘价总表：close_prices.csv

每行一个日期，固定列顺序如下：

```text
日期、IF8888.CFE、IC8888.CFE、IM8888.CFE、TS8888.CFE、TF8888.CFE、T8888.CFE、TL8888.CFE、AU8888.SHF、SC8888.SHF、CU8888.SHF、RB8888.SHF、M8888.DCE
```

采用所有品种返回日期的并集。每个品种一列收盘价；未上市或当日无返回值时为空，不补 0、不前后填充。仅处理部分品种时，不生成此完整总表。

### 下载清单：download_manifest.csv

完整运行时每个品种一行，共 12 行，固定 19 列：

| 列名 | 内容 |
|---|---|
| 代码、名称、资产类别、上市时间 | 品种基本信息；沪铜上市时间保留 YYYY-MM 精度 |
| 设定开始日期、设定结束日期 | 本次运行配置的整体区间 |
| 请求开始日期、请求结束日期 | 按上市时间裁剪后，实际向接口请求的区间；尚未上市时为空 |
| 实际开始日期、实际结束日期 | 本次返回行情的首末日期；没有行情时为空 |
| 数据行数 | 该品种实际保存的交易日数量 |
| 状态 | 已下载或尚未上市 |
| 对齐日期缺失数 | 上市后请求区间内，在所选品种日期并集中没有该品种数据的日期数 |
| 非正收盘价数 | 收盘价小于或等于 0 的记录数 |
| 数据来源 | 同花顺 iFinD HTTP API |
| 下载时间 | 本次运行时间，含上海时区偏移 |
| 序列类型 | 加权期货价格 |
| 数据频率 | D，表示日频 |
| 缺失填充方式 | Omit，表示接口不填补缺失值 |

### 异常日期表：data_issues.csv

每个异常日期一行，列为：`日期、代码、名称、资产类别、问题类型、收盘价`。

问题类型包括 `对齐后缺失` 和 `非正收盘价`。缺失记录的收盘价单元格为空；非正价格保留原值。没有这两类问题时，文件只有表头。

该表用于标记成功下载后的日期对齐缺口及非正价格。接口失败、格式错误或无效价格会直接报错并停止下载，不会作为成功结果填入此表。

### 小样本核验输出

`--probe` 模式在独立目录生成两个 CSV，不写入正式行情目录：

```text
data/futures_probe/
├── probe_report.csv
└── probe_samples.csv
```

`probe_report.csv` 每个品种、每个核验窗口一行。默认每品种最早和最近各一个窗口，通常为 24 行；两个窗口完全相同则合并，尚未上市的品种记一行状态。固定 11 列：

```text
代码、名称、资产类别、核验区间、请求开始日期、请求结束日期、实际开始日期、实际结束日期、数据行数、状态、错误信息
```

核验区间为最早区间、最近区间或最早/最近区间；状态为可查询、失败或尚未上市。成功时错误信息为空。

`probe_samples.csv` 保存核验期间取得的全部小样本行情，每行一条日期价格，固定六列：

```text
日期、代码、名称、资产类别、核验区间、收盘价
```

核验窗口有重叠时，同一代码和日期可能分别出现在两个窗口中；它是核验样本，不用于替代完整行情。

沪铜上市时间填写为 `1993-03`，依据上期所资料保留月份精度；程序仅以该月月初作为请求下界，不将其视为精确上市日。

上市日期用于裁剪请求起点。上市后的较长空段、异常的两端缺口、缺失价格及冲突重复日期会报错。20 个自然日的边界阈值用于识别历史截断，不替代交易日历核验。总表按返回日期并集对齐，清单另列各品种在该日期集上的缺口。

所有行情请求成功后才开始保存；下载失败不替换旧 CSV。保存阶段对每个文件使用临时文件再替换，单文件写入失败保留该文件旧版；整个目录不是一次性原子替换。

加权价格是供应商合成序列，不能直接视为可交易合约组合的收益。第一版只负责获取研究所需的原始日收盘价。

## 离线检查

CSV 输出已使用模拟响应检查列数、空值、异常记录和核验失败信息；检查未读取真实凭证或请求行情。
